SnakeGame

Классическая игра «Змейка», разработанная на C++ с использованием библиотеки SFML.

Проект был создан во время изучения основ разработки игр. В нём реализован полноценный игровой цикл, обработка пользовательского ввода, движение игровых объектов, генерация еды, увеличение длины змейки и проверка столкновений.

Архитектура

Логика проекта разделена между отдельными игровыми сущностями и основным игровым циклом.

В процессе работы игра последовательно выполняет следующие этапы:

Обработка событий
        ↓
Обработка управления
        ↓
Обновление состояния игры
        ↓
Проверка столкновений
        ↓
Отрисовка кадра

Такое разделение позволило отделить обработку ввода, игровую логику и отображение объектов.

Сборка и запуск
Требования
Windows;
Visual Studio 2019 или новее;
компоненты разработки классических приложений на C++;
SFML 2.5.1.
Запуск через Visual Studio

Клонируйте репозиторий:

git clone https://github.com/Weez9x/SnakeGame.git

Откройте файл решения проекта в Visual Studio, выберите подходящую конфигурацию сборки и запустите проект.

Если библиотека SFML не подключается автоматически, необходимо проверить пути к заголовочным файлам, библиотекам и DLL-файлам в настройках проекта.
